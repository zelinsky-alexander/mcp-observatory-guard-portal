# Public terminology

Use evidence-based language throughout the portal.

- **Observation:** a directly recorded property or behavior.
- **Finding:** a deterministic analysis rule matched recorded evidence.
- **Disposition:** researcher review state such as `unreviewed`, `reviewed-benign`, `suspicious`, or `confirmed-risk`.
- **Analysis complete:** the configured analysis profile finished. It is not a safety verdict.
- **No finding recorded:** no configured rule matched. It does not prove absence of risk.

Avoid unqualified labels such as **safe**, **clean**, **trusted**, or **malicious**. Future assurance conclusions must always name the exact artifact, profile, coverage and remaining uncertainty.
